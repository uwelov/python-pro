# book_list_app

Невеликий навчальний Flask-додаток для обліку прочитаних книг.

## Структура проєкту

```
book_list_app/
├─ app.py               # головний файл додатку (маршрути, логіка)
├─ templates/
│  ├─ base.html          # базовий шаблон-каркас (навігація, footer)
│  ├─ index.html         # головна сторінка зі статистикою
│  ├─ items.html         # список усіх книг у вигляді таблиці
│  └─ add_book.html      # форма додавання нової книги
└─ static/
   └─ style.css          # стилі
```

## Маршрути

| Маршрут                    | Метод(и)     | Опис                                          |
|-----------------------------|--------------|------------------------------------------------|
| `/`                         | GET          | Головна сторінка, коротка статистика           |
| `/books`                    | GET          | Список усіх книг                                |
| `/books/add`                | GET, POST    | Форма додавання книги / обробка відправлення   |
| `/books/<int:book_id>/toggle` | POST       | Перемкнути статус "прочитано / не прочитано"   |

## Зберігання даних

Дані зберігаються в оперативній пам'яті процесу (список словників `books`
у `app.py`, типізований через `TypedDict`). Це навчальне спрощення:
при перезапуску сервера всі додані книги скидаються до початкового набору
з трьох прикладів. Для постійного зберігання це легко замінити на SQLite
(наприклад, через `flask-sqlalchemy`).

## Типізація та документація

* Усі функції мають анотації типів аргументів і значень, що повертаються
  (`str`, `Response`, `int`, `str | Response` тощо).
* Структура книги описана через `typing.TypedDict` (`Book`), що дозволяє
  редактору/`mypy` перевіряти коректність полів (`id`, `title`, `author`,
  `year`, `read`).
* Кожна функція має docstring з описом призначення, а де є аргументи чи
  повернене значення — розділи `Args:` / `Returns:`.
* Перевірено `mypy app.py --ignore-missing-imports` — помилок типізації немає.

## Запуск

```bash
pip install flask
python app.py
```

Додаток буде доступний за адресою `http://127.0.0.1:5000`.
