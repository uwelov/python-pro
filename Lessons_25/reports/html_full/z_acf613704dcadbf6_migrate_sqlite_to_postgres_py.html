1"""Одноразовий перенос даних зі старої бази SQLite в PostgreSQL. 

2 

3Як це працює: 

4 1. читає дані зі "старої" бази (аліас `sqlite_legacy` у settings.py) через 

5 `dumpdata` у тимчасовий JSON-файл (UTF-8); 

6 2. записує їх у основну базу (`default` = PostgreSQL) через `loaddata`. 

7 

8Службові таблиці, які Django створює сам при `migrate` (ContentType, Permission), 

9і тимчасові сесії не переносяться. Групи та права користувачів переносяться 

10через natural keys, тому не залежать від числових id. 

11 

12Після `loaddata` Django автоматично скидає послідовності (sequences) PostgreSQL, 

13тож нові записи отримуватимуть id після найбільшого перенесеного. 

14 

15Команду можна запускати повторно: записи з однаковими pk просто оновлюються. 

16"""

85 """Зупиняємось, якщо в PostgreSQL уже є користувач з тим самим username,

89 User = get_user_model() 

90 legacy = dict(User.objects.using(LEGACY_ALIAS).values_list("username", "pk")) 

91 existing = dict(User.objects.using("default").values_list("username", "pk")) 

92 conflicts = [
